# SpsWebBI - Alt Grafik Stili Özel Görselleri
Bu klasöre koyacağınız PNG veya SVG görselleri, Tasarım Stüdyosu'nda (designer)
"Alt Grafik Stilleri Galerisi" panelinde otomatik olarak gösterilecektir.

Özel görsel bulunamazsa sistem dahili yüksek çözünürlüklü vektör SVG ikonları kullanır.

Dosya isimlendirme formatı:
{grafik_ailesi}_{alt_stil_kodu}.png (veya .svg)

Örnekler:
- pie_roseArea.png (Nightingale Gül Diyagramı - Alan)
- pie_donut.png (Yuvarlatılmış Halka)
- line_smooth.png (Yumuşak Eğrisel Çizgi)
- line_gradientArea.png (Gradyan Alan)
- bar_waterfall.png (Şelale Grafiği)
- gauge_progress.png (İlerleme Şeritli İbre)
- hierarchy_treemap.png (Kutu Haritası)
- hierarchy_sunburst.png (Güneş Patlaması)
- hierarchy_sankey.png (Sankey Akış Diyagramı)
- radar_polygon.png (Çokgen Radar)
- scatter_bubble.png (Baloncuk Dağılım)
